# V4JB - Vibe, atmosphere and texture and vibes

Audio plugin for making atmospheres and textures and those kind of sounds.
Very nice, very vibe, very mood.

Sister plugin to TEW03 and K1X:
- C:\Users\Mikael\src\TEW03
- C:\Users\Mikael\src\K1X

V4JB has a website like TEW03 and K1X under `./docs`.
V4JB uses JUCE (~/JUCE).
V4JB uses Justfile, like TEW03 and K1X.
V4JB creates installer with build-dist like TEW03 and K1X.
V4JB has the update checker like TEW03 and K1X.

## V4JB what it is:
- Instrument (synth, MIDI in), VST3 and Standalone. Generates textures, it does not process input audio.
- "Fog at night" colors of interface:
  - 14121f Night (background)
  - 24233a Dusk (panels, knob wells)
  - 9aa3b5 Fog (text, knob caps)
  - 6fc3b8 Teal (main accent)
  - e0a458 Amber (update notice, clip)
  - FFFFFF White
- Logo source is `./assets/logo.af`. Export `./assets/logo.png`. That PNG is the plugin logo and the Standalone EXE icon (`just icon`). The docs site uses a 512px copy at `./docs/logo.png`.
- Git repo will be shared on GitHub (iamtew/V4JB), LICENSE is MIT, README.md stays small.
