# V4JB – Product Requirements

## Vision

An instrument for atmospheres and textures: pads, drones, air, fog. Few knobs, big mood. Sister plugin to TEW03 and K1X.

## MVP

- Texture engine (to be designed, see DSP notes)
- MIDI in: notes play or tune the texture
- VST3 + Standalone
- About + GitHub tag check
- "Fog at night" UI, logo, MIT

## Non-goals

- Effect on incoming audio (it is an instrument)
- Sample library / ROMpler
- Copying commercial plugins
