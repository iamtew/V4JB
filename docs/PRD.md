# V4JB – Product Requirements

## Vision

An instrument for atmospheres and textures: pads, drones, air, fog. A modular additive synth: up to 512 sine partials per voice, shaped by a chain of spectral modules, brought to life by a morph pad. Clean, glassy, digital, always moving. Sister plugin to TEW03 and K1X.

## Shipped

- Additive engine: 8 voices, 512 partials (128 in Economy), 18 spacing algorithms, spectral modulation, spectral noise, two sub octaves
- 10 module slots, 27 modules, per-slot spectrum view, envelope / LFO / MIDI routes
- 4 envelopes, 3 tempo-syncable LFOs
- Effects: drive, chorus/phaser, ping-pong delay, reverb, width, limiter
- Morph pad: 4 corners, drawn paths (free or synced), X-axis envelope mode with snap, 11 fixed-assignment macros + offsets + one User macro
- Wave / Double Wave: shape partials from analysed audio files
- 17 factory presets, user presets, smart randomizer
- VST3 + Standalone, About + GitHub tag check, "Fog at night" UI, MIT

## Non-goals

- Effect on incoming audio (it is an instrument)
- Sample library / ROMpler
- Copying commercial plugins: their published feature lists are a reference, but code and presets are our own
